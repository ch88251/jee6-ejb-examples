POJO + Redis Examples

Plain Java services, wired by a ServletContextListener, with their state in Redis (Redisson). These were EJB 2.x beans.

  • Shopping cart: per-customer state in Redis (was a stateful session bean)
  • Currency converter: one shared stateless service (was a stateless session bean)
  • Product catalog: a Redis hash (was a CMP entity bean)
  • Asynchronous price changes: a Redis queue and a worker thread (was a message-driven bean)
